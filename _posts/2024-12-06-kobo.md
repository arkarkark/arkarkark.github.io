I've had a kobo Aura HD that a friend sold me for about 10 years now. I liked it way more than the old nook I was using (although I missed the page turn buttons) and the fact I got both of these readers for less than $30 meant I was always reluctant to spend the money a new one would cost. However I finally got so fed up with the Aura being so slow I could only really turn pages and often it would get in a mode where each page turn forward took it back a page and I'd have to reboot. So I got myself a new reader with page turn buttons and that meant the [Kobo Libra Color](https://us.kobobooks.com/products/kobo-libra-colour). I don't regret it one bit.

I've been filling it up with [kepub
files](https://standardebooks.org/help/how-to-use-our-ebooks#kobo-faq) from [standard
ebooks](https://standardebooks.org/). kepub files use a better renderer and are much faster. I converted all my old .epub files into kepub by using [kepubify](https://pgaskin.net/kepubify/). They even have a
[web version](https://pgaskin.net/kepubify/try/) if you can't install the command line one.

I got a cheap [case](https://www.aliexpress.us/item/3256807833568422.html) from aliexpress and it's great.
I also got some [screen protectors](https://www.aliexpress.us/item/3256807542569497.html) too. I also orderd various [bluetooth ring page turners](https://www.aliexpress.us/w/wholesale-bluetooth-ring-page-turner.html) and I'll report back when I find one I like I'm trying [this](https://www.aliexpress.us/item/3256807276464597.html) and
[this](https://www.aliexpress.us/item/3256806042308101.html)

To use the page turners I'm using [btpt](https://github.com/tsowell/kobo-btpt) which allows you to specify commands for each button. I also installed
	[nickelmenu](https://pgaskin.net/NickelMenu/) to quickly allow me to turn on bluetooth with a menu item. It's early days and I needed to get a nightly build for bluetooth support. To install the nightly version get one of the artifacts from a green build on [this page](https://github.com/pgaskin/NickelMenu/actions/workflows/build.yaml). I followed the instructions in
[this thread](to get bluetooth to connect).

You can get free books from the following places in order of preference.

 * [standard ebooks](https://standardebooks.org/)
 * [alice & books](https://www.aliceandbooks.com/)
 * [project gutenberg](https://www.gutenberg.org/)
 * [archive.org](https://archive.org/details/texts&tab=about)
 * [get comics](https://getcomics.org/)

I've also got on board with some of the connected features of the kobo platform. I now keep all my kepub books in [dropbox](https://dropbox.com/) and have them sync to the device automatically. I would keep them in Google Drive (where I had them previously stored), but it seems to need access to all your google drive files rather than just a single directory like it does with dropbox. I did have to flatten my very organized directory structure since dropbox seems to only sync the root directory unless you tell it to sync seach subdirectory one by one.

I also got on board with [pocket](https://getpocket.com/saves) to save web articles and then read them later. I found the official pocket chrome extension to want too many permissions (all websites!) but the
[save to pocket privacy edition Chrome Extension](https://chromewebstore.google.com/detail/save-to-pocket-privacy-ed/foggicgimbemdljifmnlandgnknipibf) only gets permission when you click on it. I also use the [feedly pocket integration](https://docs.feedly.com/article/498-share-save-to-pocket) to save long rss articles for reading later.

I haven't yet played with [koreader](https://koreader.rocks/) but I might give that a go at some future date.
